Brnění má více možností jak bude implementované. Buď to bude redukovat přímo DMG a nebo rovnou úspěchy. Pravděpodobnější možností je redukce úspěchů.

Další proměnná je, jestli bude brnění statické a bude fungovat proti každému útoku nebo bude mít určitý počet použití, kterého hráči mohou takticky využít. Po té by se brnění muselo nějak opravit.

| Jméno           | Bodný útok | Sečný útok | Tupý útok |
| --------------- | ---------- | ---------- | --------- |
| Kožená zbroj    | 0          | 0          | 1         |
| Kroužková zbroj | 0          | 1          | 0         |
| Plátová zbroj   | 1          | 0          | 0         |
